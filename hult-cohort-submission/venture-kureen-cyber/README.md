## Product summary

CBManagement is a production SaaS for Trinidad & Tobago / Caribbean SMEs: POS, inventory, customers, jobs, invoices, payments, expenses, reports, and settings (theme, VAT, printers). Auth via Supabase; business data on Postgres for cross-device persistence.
